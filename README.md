【项目描述】针对大型科技园区、写字楼员工的饮食预订系统，旨在解决高峰期点餐拥堵与个性化推荐缺失问题。
【技术栈】Spring Boot, Redis, MySQL, MyBatis, Claude Code,  AOP
•智能点餐赋能：针对用户在海量菜品中选择困难的痛点，设计并落地了基于大模型的“智能点餐助手”。设计了 Redis 菜单快照缓存机制，将实时在售菜品精简后注入 System Prompt，解决了 AI 无法感知实时业务数据的“幻觉”问题。 实现了基于预算与口味偏好的智能推荐闭环，通过 Hutool-Http 封装与异常兜底逻辑，确保了在高延迟网络环境下的服务稳定性。
•基础架构设计： 基于 Spring Boot 构建后端核心服务，
•高并发读优化： 针对午餐时段极高 QPS 压力，引入 Redis 实现热点商品多级缓存。针对缓存击穿，采用逻辑过期与互斥锁方案，保障系统高可用。
•高并发写控制： 针对限量套餐抢购，基于 Redis 分布式锁与 MySQL 乐观锁防止商品超卖，确保库存扣减的最终一致性。
