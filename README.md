# 智慧园区团餐中台 (Smart Campus Catering System)

本项目是一款针对大型科技园区、写字楼员工设计的饮食预订系统，核心旨在利用 Java 后端技术栈与 AI 大模型能力，解决高峰期点餐拥堵与用户个性化推荐缺失的业务痛点。

---

## 🛠️ 技术栈
- **核心框架**：Spring Boot, MyBatis
- **中间件**：Redis, MySQL
- **AI 协作**：Claude Code, DeepSeek/OpenAI API
- **工程化工具**：AOP, Hutool-Http, Maven, Git

---

## 🚀 核心功能与技术亮点

### 🤖 智能点餐赋能 (AI-Native Integration)
针对用户在海量菜品中选择困难的痛点，设计并落地了基于大模型的“智能点餐助手”：
* **实时上下文感知**：设计了 **Redis 菜单快照缓存机制**，将实时在售菜品精简后动态注入 System Prompt，有效解决了 AI 无法感知业务实时变化的“幻觉”问题。
* **推荐闭环实现**：实现了基于用户预算与口味偏好的智能推荐逻辑，通过 **Hutool-Http** 封装请求。
* **服务容错与降级**：设计了完善的异常处理与**业务兜底逻辑**，确保在 API 高延迟或网络波动环境下系统的服务稳定性。

### 🏗️ 基础架构设计
* 基于 **Spring Boot** 构建高性能后端核心服务，遵循典型的 Controller-Service-Mapper 分层架构。
* 利用 **AOP (面向切面编程)** 实现了全局统一的日志记录与异常处理机制，降低业务代码耦合度。

### ⚡ 高并发读优化 (High-Concurrency Read)
* 针对园区午餐时段极高的 QPS 压力，引入 **Redis 实现热点商品多级缓存**。
* 针对**缓存击穿**风险，采用了 **逻辑过期** 与 **互斥锁** 结合的方案，在保障系统高可用的同时维护了数据的一致性。

### 🔒 高并发写控制 (Concurrency Control)
* 针对限量特价套餐抢购场景，基于 **Redis 分布式锁** 与 **MySQL 乐观锁** 构建了双重校验机制。
* 有效防止了极端并发情况下的商品超卖问题，确保库存扣减的最终一致性。

## 📂 项目结构描述
- `sky-common`: 基础工具类、常量及 AI 配置属性映射类
- `sky-pojo`: 包含 DTO、VO 及实体类
- `sky-server`: 核心业务逻辑实现、Controller 接口及 AI 服务层实现
